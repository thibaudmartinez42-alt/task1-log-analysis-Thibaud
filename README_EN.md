# Assignment IV - Secure Local API Configuration

## Project Overview
This project consists of a secure RESTful API built with **Node.js** and **Express**. It was designed to manage a network device inventory while implementing industry-standard security protocols.

## Security Architecture
- **Transport Layer Security (HTTPS)**: The server communicates exclusively over HTTPS using OpenSSL self-signed certificates (server.key & server.cert).
- **Authentication**: Implements stateless **JSON Web Tokens (JWT)** for secure user sessions.
- **Role-Based Access Control (RBAC)**:
  - **User (tech)**: Can only perform Read operations (GET).
  - **Admin (admin)**: Full privileges, including Resource Creation (POST), Deletion (DELETE), and Security Log access.

## API Documentation & Endpoints

### Authentication
- **URL**: POST /login
- **Payload**: { "username": "admin", "password": "admin123" }
- **Response**: Returns a Bearer Token valid for 1 hour.

### Device Management
- GET /api/devices: Retrieve the full list of devices (Requires JWT).
- POST /api/devices: Add a new device (Admin only).
- DELETE /api/devices/:id: Remove a specific device (Admin only).

### Monitoring & Logging
- **Endpoint**: GET /api/logs (Admin only).
- **Functionality**: Accesses the ccess.log file generated by the morgan middleware. 
- **Data captured**: Client IP, Timestamp, HTTP Method, Request URL, Status Code, and Response Time.
